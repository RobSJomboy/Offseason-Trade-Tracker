# Offseason Trade Tracker

Talkin' Baseball graphics for every MLB offseason trade since the 2021–22 winter (data through Nov 15, 2026).
Built like Savant Spotlight: a control page you click through and a 1920×1080 OBS display.

- **Control:** https://robsjomboy.github.io/Offseason-Trade-Tracker/
- **OBS:** hit *Copy OBS URL* on the control page (`display.html?room=…`), Browser Source at 1920×1080.

Graphics: five talking points, this winter so far, pace, trades per winter, by month, trade machines, big money,
plus a trade card and a team card for whatever you pick from the list on the left.
Keys: ← → step graphics · ↑ ↓ step the list · A on/off air · / search · 1–9 jump.

Files: `index.html` (control), `display.html` (OBS), `tt.js` (graphics + relay), `tt.css`, `data.js` (trade data).
